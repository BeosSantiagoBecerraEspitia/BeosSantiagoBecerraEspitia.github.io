# Beos Becerra Espitia — Developer Portfolio

A responsive, dark-themed developer portfolio built with **Astro** and **Tailwind CSS** for Beos Becerra Espitia, a Systems Engineer / Cloud & DevOps professional based in Bogotá, Colombia.

## Sections

- **Hero / About** — Personal summary, skill tags, stats, and social links
- **Work Experience** — Timeline of professional positions with highlights
- **Projects** — Grid of open-source projects with tech tags and GitHub links
- **Education & Certifications** — Academic background and professional certifications
- **YouTube Videos** — Placeholder video cards linking to the YouTube channel
- **Contact** — Call-to-action with social/contact links and footer

## Tech Stack

- [Astro](https://astro.build) v4
- [Tailwind CSS](https://tailwindcss.com) v3
- [@astrojs/tailwind](https://docs.astro.build/en/guides/integrations-guide/tailwind/) integration
- TypeScript
- Vanilla JS (mobile menu, scroll effects)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

## Build

```bash
npm run build
npm run preview
```
